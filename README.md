# Internet Speed Meter

Небольшой консольный скрипт для приблизительного замера скорости скачивания.
Он последовательно выполняет 10 запросов к указанному URL, полностью читает
каждый ответ и выводит:

- время и объём каждого скачивания;
- среднее время одного запроса;
- общий объём скачанных данных;
- среднюю скорость в MB/s.

Сторонние библиотеки не нужны — достаточно Python 3.9 или новее.

## Установка CLI-команды

Из папки репозитория выполните:

```bash
python -m pip install .
```

После этого команда доступна из любого каталога:

```bash
speed-meter "https://example.com/large-image.jpg"
```

## Запуск без установки

```bash
python speed_meter.py "https://example.com/large-image.jpg"
```

На Windows также можно использовать:

```powershell
py speed_meter.py "https://example.com/large-image.jpg"
```

По умолчанию выполняется ровно 10 последовательных запросов. При необходимости
число запросов и тайм-аут можно изменить:

```bash
python speed_meter.py "https://example.com/large-file.bin" --requests 10 --timeout 120
```

Справка по всем параметрам и версия:

```bash
speed-meter --help
speed-meter --version
```

## Пример вывода

```text
URL: https://example.com/large-image.jpg
Запросов: 10

[01/10] 1.247 с, 5.120 MB
...
[10/10] 1.183 с, 5.120 MB

Итоги:
Среднее время запроса: 1.215 с
Скачано данных:        51.200 MB (51200000 байт)
Средняя скорость:      4.214 MB/s
```

## Как считается скорость

```text
скорость = общий объём скачанных данных / суммарное время всех запросов
```

Здесь `1 MB = 1 000 000 байт`. Время включает установку соединения, ожидание
ответа и полное чтение тела ответа. Запросы выполняются последовательно, без
параллелизма. Если любой запрос завершается ошибкой, программа сообщает об этом
и возвращает ненулевой код завершения.

Для более устойчивого результата используйте достаточно большой статический
файл. Учтите, что сервер или промежуточный CDN может кэшировать данные и
ограничивать скорость.
